# Security

This is a static website: no server code, no forms, no cookies, no tracking, no third-party scripts.

**Found a problem?** For example a fake QR sticker on a poster, a page asking for money, or a vulnerability in this repository.
Report it privately via *Security → Report a vulnerability* on GitHub, or mail burengroep.heizijdsevelden@proton.me.
Please don't open a public issue for security problems.
